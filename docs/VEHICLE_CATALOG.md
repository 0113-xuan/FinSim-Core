# 車款選擇第一版

核對日期：2026-10-11。清單是官方資料快照，非完整車型庫、即時成交價或市場推薦。

## 使用

在 `vehicle.html` 的「選擇車款」選一個版本，設定年里程與油價，按「帶入車價與油費」。只修改車價與每月油費，不覆寫頭期款、利率、保險、稅費、維修或停車預算。所有金額仍可修改，重新確認後才執行原購車評估。

選擇自訂車款會保留目前金額。修改里程或油價後必須再次帶入；尚未帶入的新選項不會被標成已評估車款。請求有逾時與舊回應保護；清單失敗仍能手動填寫。

## 資料

- Toyota Corolla Cross 汽油豪華、HYBRID 豪華、HYBRID 旗艦：Toyota 官網2026-10資料版本。
- Honda HR-V e:HEV S、e:HEV Prestige：Honda 2025-06-17發表公告，保留公告日期，不宣稱即時售價。
- 每筆保留官方網址、版本、核對日與TWD幣別。油耗為官方實驗室測試值。
- 年里程15,000km與油價NT$30/L僅是可修改規劃假設。
- 月油費由後端計算：年里程 / km每公升 * 油價 / 12。未加入AI推估。
- 保險、稅費與維修仍是原規劃假設，並未完成個別車款校準。

## API

- `GET /decisions/vehicle/catalog`：5筆車型。
- `POST /decisions/vehicle/preset`：`vehicle_id`、`annual_distance_km`、`fuel_price_twd_l`，回傳車價與月油費。未知車型、額外欄位、負值與非有限值回傳422。
- 原購車請求可選擇加入 `vehicle_catalog_id`。原回應新增 `selected_vehicle`；沒有選擇時為null，舊請求保持相容。
- 金額來源與計算依據保留於情境輸入及回傳provenance；使用者修改時移除舊計算依據。

## 驗證

Python288項、Node53項通過；2則既有JWT測試金鑰長度警告。瀏覽器驗證兩款車帶入、保留手動車價、來源送至後端及結果車名，390px手機無整頁橫向溢出。原車輛計算引擎未重寫。

後續可增加車型、電車能耗及校準資料；本次未加入選車測驗或獨立多車規格比較頁。
