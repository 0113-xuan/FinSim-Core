## 改了什麼

1. **6 張「即將推出」卡片 → 一行文字**
   - `static/event-picker.js`：只畫可用的範本（購車、換工作、一次性收支、期間每月收支），最後加一行「之後會加入：買房、搬家、結婚、生小孩、旅遊、進修。」。選定範本鎖定時不顯示這行。
   - 原本 6 張無法操作卻留在 Tab 順序的卡片不見了；`shell.css` 移除不再使用的 `.template-badge`。
   - `event-templates.js` 的資料沒動：`?add=home` 這類網址仍被忽略，既有測試不變。
2. **「一個計畫一個事件」的文案矛盾**
   - 建立計畫對話框：「之後在計畫頁還可以加入更多事件。」→「一個計畫放一個事件；想比較其他情況，可以另外建立計畫。」；標題「想先加入什麼事件？」→「這個計畫要安排什麼事件？」。
   - 計畫頁：「事件時間軸」→「計畫事件」；開頭說明改為「安排一個事件，看看它對未來現金與淨資產的影響。」；空狀態「尚無事件，從下方新增第一筆。」→「還沒有事件，請從下方選一個。」。
3. **購車表單選項**
   - 保養、油電、折舊率三個選填欄位收進一個預設收合的「保養、油電、折舊（選填，不填就用系統預設值）」。購車表單一開始少 3 個欄位。
   - 編輯已存事件時，若這三格有值會自動展開；欄位值不合法（例如小數位過多）送出被擋時也會自動展開，不會靜默失敗。
   - 摺疊標題（含「看全部數字」）用 flex 排版後瀏覽器的三角形消失，補上「＋／－」指示。
4. 測試：新增 picker 假 DOM 測試、文案與摺疊結構測試。JS 243 通過、Python 937 通過。
