## 任務 1（P1）：從汽車停車場參考中排除機車專用停車場

目前快照裡有 24 間機車專用停車場，其中 8 間有月租價，例如：
- 新竹市後站機車第二停車場 300 元
- 高雄市俥亭左營高鐵機車停車場 1000 元
- 花蓮縣停佳安（花蓮停四）機車停車場 900 元

士林區的清單裡也會出現「捷運士林站橋下機車停車場」。

**規則**：停車場名稱（`CarParkName.Zh_tw`）同時符合下面兩個條件時，就排除，不放進快照的 `lots`：
1. 名稱含有「機車」。
2. 名稱**不含**「汽車」、「汽機車」、「小型車」。

注意事項：
- **不要用「自行車」排除**。「苗栗縣舊山線鐵道自行車停車場」是觀光景點的汽車停車場，要保留。
- 名稱像「○○汽機車停車場」的要保留。
- 這個規則只看名稱，不要用收費文字推測車種。

**位置**：在 `app/parking.py` 寫一個小函式（例如 `is_scooter_only(name)`）。在 `normalize_tdx` 去重之後過濾，或在 `build_snapshot` 裡過濾，選一個地方就好。

**快照紀錄**：每個縣市記錄被排除的數量，例如 `excluded_scooter_only: 10`。
- `coverage.total` 改成排除後的數量。
- `SOURCES.md` 寫明這條排除規則，以及每個縣市排除了幾間。

**預期**：排除後全快照少 24 間。

## 任務 2（P1）：「年租:16000元 / 月租:1500元」不可以解析成 16000

**位置**：花蓮縣特翊重慶停車場。目前 `parse_monthly_rent('年租:16000元 / 月租:1500元')` 回傳 16000，正確答案是 1500。

**原因有兩個**：
1. `suffix_month` 的 `\s*/\s*月` 會把「16000元 / 月租」裡的「/ 月」當成「元/月」。
2. `RATE` 和 `OTHER_PERIOD` 沒有「年租」、「季租」、「半年租」。

**修正方式**：
- `suffix_month` 改成「/月」後面不可以緊接「租」、「繳」、「票」。
- 把「年租」、「季租」、「半年租」加進 `RATE` 和 `OTHER_PERIOD`。要放在「月租」的判斷不會被搶先匹配的位置，例如「半年租」要排在「年租」前面。

**新增測試**，放在 `tests/test_parking_multi_city.py` 或現有的月租測試裡：

| 原文 | 應解析出的月租 |
| --- | --- |
| `年租:16000元 / 月租:1500元` | 1500 |
| `季租:9000元、月租:3300元` | 3300 |
| `月租3000元，年租30000元` | 3000 |
| `月租1500、半年租1300/月` | 1500（苗栗縣北苗市場的真實寫法；半年租不算） |
| `年租:20000元` | `null` |

上一個任務的 19 個真實寫法必須全部維持原本的結果，不可以有任何一個改變。
