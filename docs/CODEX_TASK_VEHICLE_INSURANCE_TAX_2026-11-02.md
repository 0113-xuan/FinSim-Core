# Codex 任務：購車事件的保險明細與官方稅費

日期：2026-11-02。完成後由 Claude 審查。

**前置條件**：`docs/CODEX_TASK_PLAN_MODAL_EVENT_PICKER_2026-11-02.md`（建立計畫對話框與事件選擇）必須已經完成並通過審查。這份任務會修改同一個購車表單。

## 背景

- 現在購車表單的持有成本只有五個數字欄位：保險（年）、稅費（年）、保養、油電、停車。
  - 保險預設 20,000／年，只是預算，不是報價。
  - 稅費預設 12,000／年，也沒有依車款計算。
- 使用者不知道保險要保哪些、各要多少錢，也不知道稅費是怎麼來的。教授的主要意見是「可信度不夠」，這兩個預設值正是可信度最弱的地方。
- **這次的改法**：
  - **稅費**：依排氣量和燃料種類，用政府公告的稅額表計算，並顯示來源。
  - **保險**：列出強制險和各種任意險。強制險一定要保，任意險讓使用者勾選。每一項都顯示參考保費，下方加總。
- 原則不變：**數字由 Python 計算**，前端只負責顯示和收集使用者的選擇。

## 任務 A：後端的稅費與保險參考資料

1. **新增 `app/vehicle_fees.py`**，內容包括：
   - 上面兩張稅額表，以及資料來源的網址、公告或更新日期、查證日期。
   - 保險參考資料：險種代號、中文名稱、一句白話說明、參考保費範圍、預設值、來源。
     - 險種代號：`compulsory`、`third_party`、`excess_liability`、`body_a`、`body_b`、`body_c`、`theft`。
     - `body_a`、`body_b`、`body_c` 三擇一。

2. **純函式**
   - `annual_vehicle_tax(displacement_cc, fuel_type)`：
     - `fuel_type` 是 `gasoline`、`hybrid`、`diesel` 或 `ev`。油電混合（hybrid）的稅費和汽油車相同。
     - 回傳 `{license_tax, road_fee, total, notes, sources}`。
   - `insurance_reference(purchase_price)`：回傳每一項的 `{id, name, description, required, low, high, default, source}`。
     - 車體險的預設值 = 車價 × 比例，比例取上面 finfo 範例的 5.2%、2.9%、1.2%，四捨五入到百元。
     - 車體險的 `description` 要寫明「依單一範例車款的比例估算」。

3. **車款清單新增欄位**：`displacement_cc`、`fuel_type`、`spec_source`。數字從原廠規格頁取得，`spec_source` 填原廠規格頁網址。
   - Corolla Cross 汽油、HYBRID：1798 cc。
   - HR-V e:HEV：1498 cc。
   - 回報時請列出你查到的原廠規格頁網址。

4. **新增 `GET /planner/vehicle-fees`**
   - 參數：`displacement_cc`、`fuel_type`、`purchase_price`。
   - 回傳：`{tax: annual_vehicle_tax(...), insurance: insurance_reference(...)}`。
   - 參數錯誤時回 422，訊息用繁體中文。

5. **`PlannerVehicleDetails` 新增選填欄位**（只用來存明細，計算時不讀）：
   - `displacement_cc`、`fuel_type`。
   - `insurance_items`：`[{id, amount}]`，`id` 必須是上面的險種代號；`compulsory` 必須存在；車體險最多一種。
   - 驗證規則：
     - 有 `insurance_items` 時，`annual_insurance` 必須等於各項金額加總（容許 1 元以內的誤差）。
     - 不符合時回 422，訊息用繁體中文。
   - 現有的計算繼續只用 `annual_insurance` 和 `annual_tax`，結果不可以改變。

## 任務 B：購車表單

1. **車款與排氣量**
   - 選了清單中的車款：自動帶入排氣量和燃料種類，唯讀，旁邊註明「原廠規格」。
   - 選自訂車款：使用者自己填排氣量和燃料種類，排氣量必填。燃料種類的選項是「汽油／油電混合／柴油／純電」。
   - 排氣量、燃料種類或車價改變時，重新呼叫 `/planner/vehicle-fees`。

2. **稅費區塊（年）**
   - 分項顯示：
     - 使用牌照稅 7,120
     - 公路養管費 4,800
     - 合計 11,920
   - 每一項附來源連結，用小字。電動車要顯示免稅說明。
   - 合計自動填入 `annual_tax`。使用者可以改成自己的金額，改過之後顯示「已改為自訂金額」和「恢復官方金額」按鈕。
   - 規費（例如 Toyota 試算中的 1,250 元）屬於購車當月的一次支出。**這次不納入計算**，只在稅費區塊下方用一句話說明。

3. **保險區塊（年）**
   - **強制險**：
     - 永遠勾選、不能取消，標示「依法必保」。
     - 金額可以修改，預設值和範圍照任務 A。
   - **任意險**：
     - 第三人責任險、超額責任險、竊盜損失險：各一個勾選框。
     - 車體損失險：「不保／甲式／乙式／丙式」單選。
     - 每一項顯示名稱、一句白話說明、參考範圍和金額輸入框。金額預設帶入參考值，使用者可以修改。
   - **預設勾選**：強制險、第三人責任險、超額責任險、車體險乙式。這是一般新車車主常見的組合。
   - **下方加總**：「保險合計：NT$xx,xxx／年」，即時更新，並自動填入 `annual_insurance`。
   - 區塊下方固定顯示：「以上為網路公開資料的參考保費，各保險公司報價不同，請以實際報價為準。」

4. **存檔與編輯**
   - 存檔時，`details` 存入：
     - `displacement_cc`、`fuel_type`
     - `insurance_items`：只存有勾選的項目
     - `annual_insurance`：保險加總
     - `annual_tax`：使用者最後確認的金額
   - 編輯既有事件時，依 `insurance_items` 還原勾選和金額。
   - 舊事件沒有 `insurance_items` 時，只顯示原本的 `annual_insurance` 數字，並提示「可重新選擇保險項目」。

5. **時間軸摘要**：在原本的摘要後面加上「保險 NT$xx,xxx／年、稅費 NT$xx,xxx／年」。

6. **購車分析**：「購車分析」按鈕送給 `/decisions/vehicle` 的 `annual_insurance` 和 `annual_tax`，改用上面的加總和稅費，不再留空讓後端套用預設值。
