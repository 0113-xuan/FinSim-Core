### P1-1　機車停車場混進汽車停車場的參考清單

快照中有 25 間停車場名稱含「機車停車場」或「自行車」，例如士林區的「捷運士林站橋下機車停車場」。其中 8 間有月租價，會拉低該區的中位數和最低價：

| 停車場 | 月租 |
| --- | ---: |
| 新竹市後站機車第二停車場 | 300 |
| 新竹市南大路機車停車場 | 300 |
| 新竹市勞山新村機車停車場 | 300 |
| 高雄市棨賢滇池機車停車場 | 500 |
| 高雄市棨賢中山機車停車場 | 500 |
| 高雄市俥亭左營高鐵機車停車場 | 1000 |
| 高雄市寶盛文府路機車停車場 | 1000 |
| 花蓮縣停佳安（花蓮停四）機車停車場 | 900 |

使用者在買車時看到這些價格會誤以為是汽車月租。

**建議修正**：
- 在 `normalize_tdx` 或建快照時，排除名稱含 `機車停車場|機車場|自行車|腳踏車` 的停車場。
- 重算 `coverage`，並在 `SOURCES.md` 寫明排除規則和排除的數量。

### P1-2　「年租:16000元 / 月租:1500元」被當成月租 16000

- **位置**：花蓮縣特翊重慶停車場。
- **原因**：
  - `suffix_month` 的 `\s*/\s*月` 會把「16000元 / 月租」裡的「/ 月」誤認成「元/月」。
  - 而且 `RATE` / `OTHER_PERIOD` 沒有「年租、季租、半年租」。
- **建議修正**：
  - `suffix_month` 改成「/月」後面不能接「租、繳、票」。
  - 「年租、季租、半年租」加進 `OTHER_PERIOD` 和 `RATE`。
  - 加測試：`'年租:16000元 / 月租:1500元'` 應該得到 1500。

我另外測了兩個寫法，目前結果正確，可以一起加進測試：
- `'季租:9000元、月租:3300元'` → 3300
- `'月租3000元，年租30000元'` → 3000

### P2-1　來源連結的 `.replace('{city}', …)` 沒有作用

`parking-form.js` 用的是 `data.source.url`，值是 `https://tdx.transportdata.tw/`，裡面沒有 `{city}`。功能上連到首頁是對的，但這行程式碼看起來像要連到各縣市 API，容易誤導。建議拿掉 `.replace`。

另外 `LocationModel.parkingPresentation()` 回傳的 `source` 欄位沒有被用到，可以刪掉。

### P2-2　高雄捷運轉乘停車場每月 300 元

例如 O8、O9 的轉乘停車場，原文是「計次每次 30 元、月租每月 300 元」，沒寫車種。300 元比較像機車價，但我無法從原文確認，所以不列為錯誤。口試展示高雄時避開這兩站就好。
