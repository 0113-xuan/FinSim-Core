## 二、車廠官網（建議售價與規格）

- 範圍：共 31 筆車款，包含 Toyota、Honda、Kia、Volvo、Lexus；每筆保留價格來源網址與自己的查核日（2026-11-04）。
- 價格取**官網建議售價**，不含經銷商價、促銷價、加價選配或成交價；規格取同官網或其官方 PDF。
- 逐筆核對結果在 `data/vehicles/existing_price_audit_20261104.json`、`new_vehicle_audit_20261104.json`。
- 已知缺口：
  - Tesla 訂購頁回 HTTP 403，價格無法核對，維持舊值並標 `indexed_only`。

  - 座位數部分來自第三方（U-CAR）或環境部綠色生活網，已標示來源類型。

## 四、系統規劃假設（不是資料，可由使用者修改）

放在 `app/decision_assumptions.py`，介面都標示為「規劃假設，非報價／非成交資料」。

- 通膨率預設 2%；年調薪率預設等於通膨率。
- 車輛年折舊率預設 15%，並未用中古車成交資料校準。
- 保險預算 20,000 元/年、稅費 12,000 元/年、保養 18,000 元/年、油電 3,000 元/月、停車 2,000 元/月。
- 預備金至少 3 個月、購車後每月結餘至少 5,000 元。
- 壓力測試：收入 ×0.9、失業 3 個月、突發支出 10 萬元、利率 +2%。
- 模擬規則：現金不足時不自動賣出投資，也不自動借款。

## 五、使用者輸入與 AI 產生的內容

- **使用者輸入**（收入、支出、負債、事件等）存在 Supabase（profiles、debts、plans、plan_events），是使用者自己的資料。
- **蒙地卡羅結果**（現金不足機率、淨資產分位數）由 CPI 與台股歷史資料經 block bootstrap 抽樣產生，抽樣說明見 `sampling_note`。
- **AI 白話解釋與方案問答**：由外部模型（OpenAI／Gemini）產生；數字由後端提供，AI 只寫文字。知識庫在 `data/knowledge/*.md`，是自己寫的說明文件，每條都標註對應的程式與資料來源。

## 六、口試或會議可能被問到的風險

1. **台股報酬指數授權未確認**：證交所端點的歷史檔沒有附個別授權，`SOURCES.md` 已寫明「尚未確認其重製、散布授權」。學術展示通常沒問題，但**公開發布前要確認**。
2. **台股歷史偏樂觀**：2003 年起的台股表現好，程式已在輸出中加警語「過去報酬不代表未來」。
3. **行業薪資是平均，不是起薪**：初出社會的人實際通常較低；半年累計且是初步統計，會再修訂。
4. **停車資料不完整**：新北、台中、基隆 TDX 回 0 筆，不代表沒有停車場；含月租字樣的 679 筆中有 16 筆未解析，原因包括季繳、國字金額、原文被截斷、只有機車月租，`data/parking/SOURCES.md` 列出每筆原文。
5. **任意險不是官方報價**，且沒有蒐集足以核保的個人條件。
6. **車價是快照**，不是即時價，也不是成交價。
7. **折舊率 15% 與各項預算是假設**，沒有經過校準。
