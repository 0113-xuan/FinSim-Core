## 任務 A：多縣市快照

1. **縣市代號對照表**：TDX 的 City 代號（例如 `Taipei`、`HsinchuCounty`）對應到 `data/regions/tw_districts.json` 的縣市名稱（例如「臺北市」「新竹縣」）。
   - 注意 TDX 地址常寫「台」，行政區清單寫「臺」，比對時要統一。
2. **行政區**：`TownName` 有值時優先使用；沒有時，從地址取出該縣市的行政區。
   - 只接受 `tw_districts.json` 裡屬於這個縣市的行政區名稱，例如臺北市只接受「士林區」「信義區」等。不可以自己猜。
   - 地址裡找不到時，再用停車場名稱比對一次（例如名稱寫「八德區永福停車場」）。
   - 都找不到時，`district` 留空字串，這筆不會出現在行政區清單中。另外記錄 `district_source`：`town_name`、`address`、`name` 或 `none`。
3. **去除重複**：同一縣市中 `id` 重複的停車場只保留一筆。彰化縣的「城市車旅員林惠明站」就重複出現了 3 次。
4. **輸出**：`data/parking/tw_carparks.json`，格式為
   ```json
   {
     "source": { ... },
     "cities": {
       "臺北市": {"tdx_city": "Taipei", "lots": [ ... ]},
       ...
     },
     "unavailable": ["臺中市", "新北市", "基隆市"]
   }
   ```
   - `source` 寫明快照日期 2026-11-03、授權、API 網址。
   - 每個縣市另外記錄停車場總數、有行政區的數量、有月租價的數量。
   - 舊的 `data/parking/taichung_carparks.json` 刪除，引用它的程式和測試一起更新。
5. **`scripts/fetch_tdx_parking.py`**：

**解析規則**

- **認得的月租字樣**：「月租」「月票」「月繳」「每月」「/月」「包月」「定期票」。
- **前面的金額不影響月租**：同一句前面有計時費率、單日上限，都不可以影響後面的月租。
- **只取汽車**：排除明確標示為「機車」「公車」「大型車」「大客車」「貨車」的金額。同時有「小型車」和其他車種時，取小型車。
- **其他繳費方式不算**：「季繳」「半年繳」「年繳」的金額，就算寫成「元/月」，也不算月租；只有沒有月繳或月租時才回傳 `null`。
- **有多個月租時**：取「全日」的；沒有全日就取最高的。
- **保留資格限制的文字**：「里民優惠」「身障」這類限定資格的價格，仍然可以解析，但 `monthly_rent_text` 要保留原文，讓使用者看得到條件。
- **不解析國字數字**：國字數字（例如「二十元」）可以不處理，回傳 `null` 即可。
