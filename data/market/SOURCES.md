# 市場歷史資料來源

程式執行時只讀本資料夾的 CSV，不連網。所有數值都由 `raw/` 底下的原始檔經腳本轉換，沒有手打。

## 消費者物價指數（CPI）

| 項目 | 內容 |
| --- | --- |
| 發布機關 | 行政院主計總處 |
| 網址 | 總體統計資料庫 <https://nstatdb.dgbas.gov.tw/dgbasall/webMain.aspx?k=dgmain> |
| 查詢條件 | 「消費者物價基本分類指數」，期間民國92年1月至115年9月，月資料與年資料一起匯出，CSV 格式 |
| 使用欄位 | 「總指數」的月度列；年度列（例如「92年」）略過 |
| 基期 | 民國110年=100 |
| 下載日期 | 2026-10-31（使用者手動匯出） |
| 資料期間 | 2003-01 至 2026-09，共 285 個月 |
| 原始檔 | `raw/cpi_nstatdb.csv`（UTF-8 有 BOM） |
| 轉換腳本 | `python scripts/build_cpi.py` → `tw_cpi_monthly.csv`（`period,cpi`），民國年加 1911 |
| 授權 | 主計總處網站資料依政府網站資料開放宣告，適用「政府資料開放授權條款－第1版」；下載時未另行查證，正式發表前請再確認 |

原始檔註解：「由於受查者延誤或更正報價，最近3個月資料均可能修正。」

## 發行量加權股價報酬指數

| 項目 | 內容 |
| --- | --- |
| 發布機關 | 臺灣證券交易所 |
| 網址 | <https://www.twse.com.tw/rwd/zh/TAIEX/MFI94U?date=YYYYMM01&response=json> |
| 查詢條件 | 每次查詢一個月份的每日指數（日期為民國年），取該月最後一個交易日的數值；請求間隔至少 3 秒 |
| 指數性質 | 含現金股利再投入的報酬指數 |
| 下載日期 | 2026-10-31 |
| 資料期間 | 2003-01 至 2026-09，共 285 個月 |
| 原始檔 | `raw/twse_total_return/YYYY-MM.json`（每月一份證交所原始回應） |
| 轉換腳本 | `python scripts/fetch_twse_total_return.py --offline` 只用已存 JSON 重建 `twse_total_return_monthly.csv`（`period,close`）；不加 `--offline` 會補抓缺少的月份 |
| 授權 | 證交所網站公開資訊，著作權屬臺灣證券交易所；本專題為學術、非商業用途。使用條件請依證交所網站著作權聲明再確認 |

## 程式如何使用

`app/core/market_data.py` 取兩份資料的共同期間，計算同一個月的通膨率 `cpi_t / cpi_{t-1} - 1` 與股市報酬 `close_t / close_{t-1} - 1`，成對共 284 個月（2003-02 至 2026-09）。Monte Carlo 以 12 個月為一個區塊成對抽樣。
